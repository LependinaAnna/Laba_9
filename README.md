Домашнее задание вариант 16. Условие задачи 16.
Написать программу, выводящую на экран заданную геометрическую фигуру, нарисованную с помощью заданного с клавиатуры символа, условия заполнения фигуры и задаваемые параметры фигуры смотреть ниже (остальные константы).
